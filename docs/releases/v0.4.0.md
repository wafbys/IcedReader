# IcedReader 0.4.0

发布日期：2026-09-03

这版给书架加上**删书**：每本书封面右下角的三点菜单里可以把它移出书库。删除前会弹出确认框，确认后这本书的 epub 连同它的阅读进度、划线一起清掉——书库里不留痕迹，以后重新导入会从零开始。

## 新增

- **删书（书架）**：书架卡片封面右下角新增三点按钮，点击弹出小菜单（目前只有「从书库删除」，结构上为后续更多按书命令留了扩展位）。删除前弹系统确认框（警告样式），确认后依次：删除 `data/library/` 里的 epub 文件 → 清除该书阅读进度 → 清除该书划线。无法打开的坏书也能从菜单删除。
  - 进度与划线按与读取相同的键规则清理：`lib:` 键的同 stem 记录（如 `lib:书名-2.epub` 与 `lib:书名.epub` 视为同一本）一并清掉，避免删书后残留记录、同名书重新导入时进度“复活”。
- **交互调整**：上一版封面右上角的常驻 `×` 改为封面右下角三点菜单，删除动作仍走确认框。为给菜单提供定位锚点，卡片拆成封面与书名信息两处可点区域，行为与原来整卡可点一致。

## 其它

- 内部：`ProgressStore::remove`、`AnnotationStore::remove_book`（core）；Tauri 新增 `delete_book` 命令（校验文件名、拒绝路径穿越）；capabilities 补 `dialog:allow-ask`（`dialog:default` 不含它）。

## 下载与运行

分发文件：`IcedReader-0.4.0-windows-x64.exe`（SHA-256 `6B2C0D89B5F452944991E9FF4BDBCB0F59DA34AB9E29F82A1E1FB50BDD4B7A8D`）

拷贝到任意可写目录即可运行：书籍、进度、划线、字体、设置与 WebView 缓存都写在 exe 同级的 `data/` 下，拷走整个程序目录即带走全部状态。不要放进 Program Files。系统需 WebView2（Windows 11 自带）。

要求：Windows 10/11 x64。

## 说明

- **平台范围**：只做 Windows（10/11 x64）。本版起代码与文档不再保留其它平台（macOS / Linux / Android / iOS / 鸿蒙）的分支与路线，协议统一走 `http://icedreader.localhost`。
- 仍只支持 EPUB（2 / 3）；PDF / MOBI 等格式在接口层预留。
- 无暗色模式、无主题切换——本软件就是浅色纸。
- 尚未做：章内搜索；`Locator.cfi` 预留未填写；划线暂只支持单色与删除，彩色与笔记留待后续。

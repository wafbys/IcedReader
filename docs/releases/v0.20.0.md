# IcedReader 0.20.0

发布日期：2026-10-24

一句话：**删除划线、删除备注都改成真删**——删备注只清备注，删划线会连备注一起移除，伴生 md 不再留删除线或「已删于 …」的痕迹。

## 新增

- **删除备注**：划线备注编辑卡新增「删除备注」，走原生确认框。只清该条目的用户区，划线、保护区与摘抄行原样保留；点「取消」不会关掉编辑器，草稿还在。
- 新 Tauri 命令 `delete_note`（`notes::clear_note` → `AnnotationStore::clear_note`）。

## 改进

- **删除划线改为真删**：注释块、摘抄行与用户备注一起从伴生 md 移除，不再写 `deleted:` 和删除线留痕；因此变空的自动章标题一并清掉。正文工具条与顶栏「划线」列表两条删除路径一致，有备注时仍先确认。
- **旧档案兼容**：旧版 `deleted:` 有值的条目读取时仍按「已删除」跳过，只是本版不再产生这种留痕条目。
- 确认框与列表悬停提示同步为「真删、无法恢复」的口径。

## 验证

- `cargo test --workspace`：iced-reader 76（+3 ignored）/ core 67 / epub 34（+2 ignored）/ pdf 17（+3 ignored），全绿。
- `cargo fmt --all -- --check`、`cargo clippy --workspace --all-targets -- -D warnings` 零告警；`npx tsc --noEmit`、`npm run check:ui` 通过。
- 单测覆盖：删划线后 md 不再含注释块/备注/删除线，删备注后划线记录与摘抄行保留、备注区清空，以及清空后与下一条保护区之间的空行。
- 本轮未做真窗口人工点击核对（「删除备注」按钮与确认框的手感）。
- 发布件：`IcedReader-0.20.0-windows-x64.exe`，启动冒烟测试通过。

## 运行环境

Windows 10/11 x64。绿色便携：书库 / 进度 / 字体 / 窗口设置都在 exe 同级 `data/`，整个目录拷走即带走状态；不要装进 Program Files；系统需 WebView2（Windows 11 自带）。

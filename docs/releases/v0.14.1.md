# IcedReader 0.14.1

发布日期：2026-09-22

一句话：**质量与性能打磨版**——没有新功能；统一了错误类型与中文报错、修了一批书架 / 封面 / 重排的性能与并发问题、加了 CI，并把顶栏在窄窗下的间距收紧。

## 改进

- **顶栏（窄窗）**：窗口 ≤1180px 时收紧按钮间距，让进度区（页码 / 全书 N%）尽量整段可见；低频按钮照旧收进右上「⋯」。PDF 的「单页 / 双页 / 自动」保持常显。
  - 说明：这一版**没有**把 PDF「张数」收进「⋯」——真机复核过，默认窗口（150% 缩放下的 1120 逻辑 px）本来就能同时放下张数、书名、页码与翻页按钮，收起来是无谓的降级。
- **报错文案**：程序自己的错误提示统一为中文（此前中英混用，会直接显示在顶栏横幅）。系统 io 错误仍随操作系统语言。
- **书架 / 封面**：封面缓存满 32 改为淘汰**最旧一条**（不再整表清空），书库较大时不再每次上书架都重渲染封面；封面预热只做屏上最可能看到的前 24 本，其余交给书架的懒加载按需预热。
- **开书 / 后台分析**：打开一本已分析过的书不再重复解析信号缓存；同一本书的后台分析按（文件, 版本）去重，线程异常也不会卡住后续分析。
- **EPUB 重排**：窗口缩放用 `requestAnimationFrame` 合并多次重排，拖窗口更顺。
- **同书提示**：书架判断「同一版次的两次打包」由两两比较改为按标题序列分桶，大书库不再随书量平方增长。

## 工程（不影响使用）

- 新增 `.github/workflows/ci.yml`（Windows：fmt / clippy `-D warnings` / test / tsc / 前端 build）；`package.json` 增加 typecheck / check:ui / lint / test 脚本。
- `src-tauri` 错误类型统一到 thiserror 的 `Error`（Tauri 命令仍按同一字符串上报，前端不变）。
- 全工作区 clippy 警告清零、`cargo fmt` 全量排版；清理前端未使用导出与后端被取代的死代码。

## 验证

- `cargo test --workspace` 全绿；`cargo clippy --workspace --all-targets -- -D warnings` 零警告；`cargo fmt --all -- --check`、`npx tsc --noEmit`、`node ui/src/pdfPaging.check.ts` 均通过。
- 真机（绿色版）验证：书架封面正常、EPUB 翻页与窄窗重排正常、PDF 连续纸带翻页与跳末页正常。

## 运行环境

Windows 10/11 x64。绿色便携：书库 / 进度 / 字体 / 窗口设置都在 exe 同级 `data/`，整个目录拷走即带走状态；不要装进 Program Files；系统需 WebView2（Windows 11 自带）。

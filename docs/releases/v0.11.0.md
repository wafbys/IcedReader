# IcedReader 0.11.0

发布日期：2026-09-16

功能版：**新增 PDF 支持（第一期：只读）**——epub 与 pdf 同一个书架、同一套进度与元数据，PDF 走 SumatraPDF 式连续纸带，纯 Rust 栅格化，仍是单 exe、零 DLL。0.10.2 之后合入的顶栏与跳转修正随本版发布。

## PDF（第一期：只读）

- **打开即读**：`data/library/` 里的 `.pdf` 与 EPUB 混排、同一套排序与三点菜单；封面 = 第 1 页 400px 渲染；进度仍只存 `Locator`（`href = page/NNNN`、`fraction = 0`），沿用同一份 `progress.json`、`annotations.json` 与伴生 `<书名>.md`，不另立一套。**扩展名是身份的一部分**：同名 `.epub` 与 `.pdf` 是两本书，改名、删书、进度互不牵连。
- **渲染在 Rust，版式在前端**：`hayro` 逐页栅格化成**无损 WebP**（同一页比 PNG 小 55–69%），`lopdf` 读页数 / Info / 书签目录。**单 exe、不加任何 DLL**（接入栅格化栈后体积从 11.56 MB 长到 17.4 MB）。
- **阅读面 = 连续纸带**（用户口径「PDF 不是 EPUB」，参照 SumatraPDF）：一列纸纵向滚动、滚轮就是滚动，**没有 iframe、没有灰底分栏**。**「适应宽度」= 纸宽实时贴合窗口宽**（拖动窗口立刻跟着变，此模式恒单页）；**「适应页面」= 整页贴合窗口高**，可切「单页 / 双页 / 自动」——双页是书式配对（第 1 页单独，之后 2-3 / 4-5），够宽时「自动」自己并排。
- **键盘与跳转**：←/→ 翻页（双页按跨页）、PageDown / 空格滚一屏、Home/End 首末页；**跳转按页号**——进度区「· 跳页」输入第 N 页即把该页滚到视口顶部（越界夹到首/末页，非数字不跳），目录跳页同理。
- **页码与进度**：一页 = 一个 spine 单元（`href = page/0001`，4 位补零）；「当前页」= 视口里面积最大的那张，它决定顶栏「第 N / M 页」（并排时加「· 跨页」）与保存的进度。整条纸带的占位按 `pageSizes` 从第一帧就铺准，滚动条长度与跳页精度不必等图片加载。
- **性能**：后台预取目标页左右各 2 页（实测命中后相邻页 **0.1–0.6 ms**，冷页 18–143 ms）；内存 LRU 16 页，**不做全书磁盘缓存、不做开书预热**；栅格宽度按「纸实际显示多大 × DPR」算、Rust 再按 128px 分桶，窗口缩放不会把缓存打碎。
- **质量角标（PDF 自己的口径）**：真文字 + 字体全嵌入 + 有书签目录 = **优**；扫描 + OCR 文字层（可搜）= **良**；纯扫描无可提取文字 = **中**；打不开 / 加密在书架显示「无法打开」。悬停看理由。信号按文件版本缓存，不在书架热路径重算。
- **缺字提示**：只对「**可见**文字用了未嵌入的非标准字体」提示——扫描书（含带隐藏 OCR 文字层的）与正常嵌入字体的书都不误报。
- **目录**：直接用 PDF outline（无 outline 就不给目录，侧栏显示「本书没有目录」），不做页序长列表。

## 已知限制（PDF 第一期）

- 不支持：选中文字、划线 / 备注、搜索、任意百分比缩放、加密 PDF（打开报错）。二期从 **PDF 自己的文字算子**生成定位文字层，真文字书与「扫描 + OCR 文字层」两类都能覆盖；纯扫描书只能做区域划线。设计、实测数字与风险表见 [`docs/ideas/pdf.md`](../ideas/pdf.md)。
- PDF 不做字体替换：字形由文件本身定死（栅格化后已进位图），阅读器四槽字体对它无意义（顶栏已隐藏字号与字体面板）。
- 内存：Rust 侧常驻 154～178 MB 不随翻页增长；WebView2 进程树在 952 页的书上翻约 120 页后稳定在约 950 MB（Chromium 自己的图片缓存封顶，不再是「无限涨」，但天花板不低）。

## 修复

- **顶栏「· 跨页」误报**：它看的是「模式」而不是眼前这一行，于是封面（书式配对下单独一张）与末页落单时也写着「跨页」。改为按当前行实际张数显示。
- **顶栏进度区被长标题挤掉**：整条 `nowrap + overflow:hidden`，PDF 的 outline 标题动辄二三十字时，页码被截成「第 …」、跳转按钮被裁到点不到。改成只有标题那一段可缩并省略，页码与跳转按钮常显。
- **PDF 跳转改收页号**：原来 PDF 与 EPUB 共用「全书 N%」，而 PDF 每页等重，百分比只是页号的另一种写法。现在 PDF 给「· 跳页」（全书 % 只留给 EPUB）。
- **开发环境性能回归**：dev profile 下依赖未做优化，实测单页栅格 1.9 s（release 21 ms）、400px 封面 8.8 s（release 452 ms），阅读器在开发时像坏了一样。给依赖与 `formats-pdf` 加 `opt-level = 2`（自身 crate 仍保持 opt-level 0，断点与重编译速度不变），同一批数字降到 184 ms / 987 ms。
- 开书时的质量分析移到后台线程（原先同步阻塞，952 页的书要等约 1 s 才出画面），`open_book` / `list_library` / `get_chapter` 等命令改 async；封面不再在协议请求里栅格化（未命中返回占位并后台预热，书架识别到占位后重试）。

## 下载与运行

分发文件：`IcedReader-0.11.0-windows-x64.exe`（18,226,688 字节，SHA-256 `B314580D8804942A477D7877730BD2D963F1D4975C725F011596F50E3188FC14`，对应源码 commit `2edde56`）

拷贝到任意可写目录即可运行：书籍、进度、划线、字体、设置与 WebView 缓存都写在 exe 同级的 `data/` 下，拷走整个程序目录即带走全部状态。系统需 WebView2（Windows 11 自带）。

要求：Windows 10/11 x64。

# IcedReader 0.5.0

发布日期：2026-09-03

这版是一次**稳定与收尾**发布：修掉了点正文注文链接会弄坏阅读器的大问题，窄窗口顶栏不再挤爆按钮，并把平台范围明确收敛到 Windows。分发 exe 与代码自此一一对应（v0.4.0 的发布说明曾提前宣告平台收敛，但当时构建并不包含）。

## 修复

- **正文链接不再带崩阅读器**：章节里的 `<a>`（古籍正文的 `[1][2]` 注文链接、书内目录链接等）会被改写成本应用资源 URL。此前直接点击会让章节 iframe 从 `srcDoc` 导航到跨源资源——分栏布局随即失效、页面无法翻页、也回不到阅读状态（在注文极多的书上极易触发，如《东周列国志》每页都是 `[n]`）。现在链接在阅读器内部处理：同文件锚点翻到注文所在那一页，跨文件链接走正常章节切换，章节 iframe 依旧不开脚本。
- **窄窗口顶栏不再裁按钮**：阅读视图在窗口 ≤1180px 时，把低频按钮（打开 EPUB / 目录 / 划线 / 字体 / 全屏）收进右上角「⋯」下拉菜单（Esc 或点外部关闭）；书架、上一章 / 下一章、A−/A+、书名作者保持常显，一行排得下、不会被 `overflow` 切掉。

## 其它

- **平台收敛**：明确只做 Windows。源码移除 macOS / Linux / Android / iOS / 鸿蒙的分支与路线，`icedreader://` scheme 兼容清理，协议统一走 `http://icedreader.localhost`。本版是第一个包含该改动的发布构建。
- 构建：顶栏布局、链接拦截均纯前端改动，不影响既有书架、划线、进度数据。

## 下载与运行

分发文件：`IcedReader-0.5.0-windows-x64.exe`（SHA-256 `B2D80A563BDB5C4F8E99FDDD1B9627972BE65D08707043DBE59A606709E1B1E0`）

拷贝到任意可写目录即可运行：书籍、进度、划线、字体、设置与 WebView 缓存都写在 exe 同级的 `data/` 下，拷走整个程序目录即带走全部状态。不要放进 Program Files。系统需 WebView2（Windows 11 自带）。

要求：Windows 10/11 x64。

## 说明

- 仍只支持 EPUB（2 / 3）。
- 无暗色模式、无主题切换——本软件就是浅色纸。
- 尚未做：章内搜索；`Locator.cfi` 预留未填写；划线暂只支持单色与删除，彩色与笔记留待后续。

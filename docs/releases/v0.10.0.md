# IcedReader 0.10.0

发布日期：2026-09-06

功能版：**划线升级（黄 / 绿两色 + 备注档案）**与**书架质量分改为同书异版对比**同时落地；0.9.0 之后合入的正确性修复随本版发布。不自动合并同书。

## 划线：两色 + 备注

划线从单色变两色（黄 = 重点，含思考 / 存疑等一切有想法；绿 = 纯摘抄），并带上备注档案与全书位置：

- **两色语义，下笔即定**：选字出现色板，默认黄 / 绿；划线时选定颜色，之后不改色、不调范围。旧单色划线的 `annotations.json` 宽容兼容，不丢。
- **备注落伴生 `<stem>.notes.md`**：注释块 + 摘抄引用行是程序保护区，其余为用户笔记区，重写只动保护区、用户文字逐字保留——UI 与外部 md 软件可同写一处，备注唯一真相源。只有写了备注的划线才落档。
- **删除留痕**：删除有备注的划线先确认，正文移除、档案记删除时间保留内容（会计不涂改的留痕语义）；纯划线删除无痕。
- **按全书位置跳转**：划线记录全书位置（各章原始可见文本字符权重），顶栏「全书 N%」点击输入 0–100 可跳；划线列表带色块 / 标签 / 时间 / 备注预览，hover 划线浮出备注（换行保留）。
- 新命令 `save_note` / `read_notes`；`add_annotation` 增 color/pos，`delete_annotation` 联动 notes.md；改名 / 删书连带 `<stem>.notes.md`。
- 备注编辑卡片居中防溢出，编辑时隐藏 hover 浮窗，可整体清除备注。

## 质量分（同书异版）

角标仍是 优 / 良 / 中，用来在未读排序里把更好的版本抬上去；同书只提示、不合并。拉开差距的是这些：

- **注文**（微信词注，或传统 `<sup>[n]</sup>` 注标）算一档。科学计数的指数（`10<sup>-43</sup>`）不算注文。
- **真正的插图**（≥8 张且每张 ≥20KB，或图多到扫描截断）算一档。两张封面、1KB 装饰图不算。
- 无乱码、有作者、书内校验过的 ISBN / ASIN 仍算。
- 10 位 Kindle 内部编号不再当 ISBN。文件名上的 ISBN 只进说明（站点常把纸书号印在文件名上），不升优。
- 少量缺字 `□` 只记减分项；密度高才降为中。
- 优 = 无缺陷且至少三档长处，所以带注的 UUID 本可以压过同一书的白文本。
- 书架上已有同书时，浮层多几句对照（「同书中有注文，另本没有」等），不改角标。

旧缓存会在下次打开该书时按新规则重算；ISBN 分类在刷新书架时即按书内标识符现算。

## 修复（0.9.0 之后已合入、随本版发布）

- 目录锚点当章时，全书位置 / 划线 `pos` / notes.md「全书 N%」按切片计，不再把整份 XHTML 重复计入。
- 书名碰撞用 ` (2)` 而不是 `-N`，避免和进度键 `lib:` 别名缠在一起。
- 划线 `lib:` 别名、点选最后一个字符、切章清 HTML、iframe 键盘与中键、书内链接只认 `icedreader.localhost` 等阅读正确性。

## 下载与运行

分发文件：`IcedReader-0.10.0-windows-x64.exe`（SHA-256 `BC9D687A50C3B68C93409E950E85D67368599DAAC9F853C74D7A43CA4539C524`，对应源码 commit `62e8a3a`）

拷贝到任意可写目录即可运行：书籍、进度、划线、字体、设置与 WebView 缓存都写在 exe 同级的 `data/` 下，拷走整个程序目录即带走全部状态。系统需 WebView2（Windows 11 自带）。

要求：Windows 10/11 x64。

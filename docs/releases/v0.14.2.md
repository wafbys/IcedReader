# IcedReader 0.14.2

发布日期：2026-09-23

一句话：**删书改为移到系统回收站**——从书架删除的书（连同它的元数据与备注）不再永久删除，可从回收站还原。

## 改进

- **删书送回收站**：书架三点菜单「从书库删除」确认后，`<书名>.epub` / `<书名>.pdf`、`<书名>.md`、`<书名>.notes.md` 一起移到**系统回收站**（`src-tauri/src/recycle.rs`，Windows `SHFileOperation` + `FOF_ALLOWUNDO`），可还原；进度、划线与质量缓存仍随书清除。确认框文案已说明。
  - 已知限制：Windows 回收站有单盘容量上限，**超过上限的大文件仍会被永久删除**（系统行为，代码绕不过）。
- 单元测试不再触碰回收站（`cfg(test)` 下退化为普通删除），避免测试把临时 fixture 送进真实回收站。

## 验证

- `cargo test --workspace` 全绿；`cargo clippy --workspace --all-targets -- -D warnings` 零警告；`cargo fmt --all -- --check`、`npx tsc --noEmit` 均通过。
- 真机验证：删除一个文件后，原路径消失且该文件出现在系统回收站。

## 运行环境

Windows 10/11 x64。绿色便携：书库 / 进度 / 字体 / 窗口设置都在 exe 同级 `data/`，整个目录拷走即带走状态；不要装进 Program Files；系统需 WebView2（Windows 11 自带）。

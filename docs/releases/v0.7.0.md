# IcedReader 0.7.0

发布日期：2026-09-04

本版在 0.6.0 的书内词注基础上完善了交互，并调整书架与阅读性能；对 0.6.0 的「浏览器原生 tooltip」悬停提示改为阅读器自绘浮层。

## 功能

- **书内词注交互**：注标悬停由阅读器自绘黑底白字浮层读注文全文（注标不再带 `title`，避免与自绘浮层双弹）；注标与段后注文双向跳转——点击注标定位到对应注文，注文开头的序号可返回正文注标。
- **注文断页与返回**：注文条目整条避开分栏切断（栏底放不下时整条移到下页开头）；个别高于一栏的特长注文跨页时，续页条目尾部提供「↩返回」入口。
- **整页背景封面**：正文近空、以 body 背景图作封面的章（如资治通鉴开篇封面）在窗口内整幅完整显示，不再被裁切；普通正文章不受影响。
- **书架展示**：封面随窗口变宽而放大，按自身比例展示不裁切；封面右下操作按钮悬停封面时显示（键盘聚焦、菜单展开、触屏时保持可见）。
- **性能**：书库描述与封面按文件版本缓存，进书架/刷新不再重复打开并解析大书（资治通鉴类书从约 2 s 降到亚毫秒级命中）；章节字体统计改为按文本块 × 文字类别抽样，打开/切换大章不再逐字做 canvas 分析。

## 修复

- **进度键**：`lib:` 仅把「`-`＋数字」视为副本后缀；书名末尾的数字（如《三体3》）不再与《三体》混为同一本；纯数字书名（如《1984》）与其副本仍对齐。读写任一别名只保留一份最新进度记录。
- **坏书删除**：文件损坏但仍留在书库的书按文件名保留 `lib:` 键——书架能显示其历史进度，删除时旧进度与划线可被清除（同名重新导入后进度从零开始）。
- **章节 `lang`**：根 `<html>` 缺 `lang` 时从 `xml:lang` 或书的 `dc:language` 补齐；不再因子元素或正文中的 `lang=` 而漏补。
- **Esc 层级**：全屏下先关闭顶栏「⋯」菜单，再依次关闭划线/目录、退出全屏。
- **清理**：移除未接线的平台字体命令（CDP）及相关死代码；「本章实际渲染」统一由章节文档内的 canvas 统计提供。

## 其它

- 文档同步：翻页方式为左右键与滚轮（无点左右侧点按翻页）；分页 flow 与词注注入样式白名单、目录摊平判定门槛按实际行为写明。
- 构建：分发独立 exe 用 `npm run tauri -- build --no-bundle`。

## 下载与运行

分发文件：`IcedReader-0.7.0-windows-x64.exe`（SHA-256 `291E135F3E24CA2C93B0C38D2F249A7B1F382DE13D14243F32E6984975398EF3`，对应源码 commit `ea831d4`）

拷贝到任意可写目录即可运行：书籍、进度、划线、字体、设置与 WebView 缓存都写在 exe 同级的 `data/` 下，拷走整个程序目录即带走全部状态。系统需 WebView2（Windows 11 自带）。

要求：Windows 10/11 x64。

## 说明

- 悬停注标读全文为阅读器自绘浮层；词注宿主覆盖正文段落与标题。
- 仍只支持 EPUB（2 / 3）。
- 无暗色模式、无主题切换。
- 尚未做：章内搜索；`Locator.cfi` 预留未填写；划线暂只支持单色与删除，彩色与笔记留待后续。

# IcedReader 0.22.0

发布日期：2026-11-03

一句话：**组件升级版**——Tauri 2.12 / wry 0.57、hayro 0.9、rbook 0.7.12、lopdf 0.46；阅读交互与数据格式不变，重点在 PDF 兼容性与健壮性、EPUB 打开速度、依赖安全。

## 升级

- **Tauri 2.12.5 / wry 0.57.1 / webview2-com 0.39.1 / windows 0.62.2**：跟到当前 WebView2 绑定；wry 0.56.1 修复 Windows 上 WebView2 parent subclass 在 teardown 后重入导致的崩溃。Tauri 2.12 起不再支持 Windows 7，本项目仍只支持 Windows 10/11。
- **hayro / hayro-syntax 0.9.0**：渲染入口改用 `PixmapSettings`（缩放/背景与渲染设置分离）；启用 0.9 的文本 hinting、字形缓存与常开 SIMD；修复嵌入字体不渲染、字形名到 Unicode 映射、平铺图案/透明度、透明图缩放颜色渗出、`Tr=7` 不可见文字，以及一批畸形 PDF 的 panic / 栈溢出 / 超额分配。
- **rbook 0.7.12**：`zip` 9.0.1 + `quick-xml` 0.42，改善 EPUB 打开性能。
- **lopdf 0.46.0**：加密 key 推导、引用环、object stream 解码、畸形注解/编码/日期/溢出等修复。
- **前端**：Tauri JS API/CLI 2.12.4、plugin-dialog 2.8.4、React 19.3.1、Vite 6.4.5、`@vitejs/plugin-react` 4.7.0；`source-map-js` 升到 1.2.2，`npm audit` 清零。Vite 8 / TypeScript 7 / plugin-react 6 属大版本，留待单独升级。

## 行为与注意

- 阅读交互、数据格式、`data/` 布局不变；进度、划线、元数据无需迁移。
- hayro 0.9 默认开启 text hinting，页面像素可能与 0.21 有细微差异。如需严格保持旧输出，可在 `render_page` 里设 `RenderSettings { hinting: false, ..Default::default() }`。
- 0.9 的字形缓存目前按页创建 `RenderCache`，跨页不共享；单页内重复字形仍受益。
- PDF 渲染速度不承诺提升：0.9 改为 SIMD 常开，需用真实 PDF 量；0.7 时代的实测里 SIMD 反而略慢。

## 运行环境

Windows 10/11 x64。绿色便携：书库 / 进度 / 字体 / 窗口设置都在 exe 同级 `data/`，整个目录拷走即带走状态；不要装进 Program Files；系统需 WebView2（Windows 11 自带）。

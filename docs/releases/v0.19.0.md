# IcedReader 0.19.0

发布日期：2026-10-22

一句话：**书架支持把 EPUB / PDF 直接拖进窗口导入**；顶栏改说「书中位置 N/M」；修好同名 EPUB/PDF 互相挤占 `(2)`，以及整页封面在最大化时标题错位。

## 新增

- **拖拽导入**：把 `.epub` / `.pdf` 拖进窗口，出现「松开导入到书库」覆盖层；松手后批量导入，**不自动打开**。同名文件已在书库则复用，不覆盖、不另存；不支持的文件跳过；结果在底部提示（已导入 / 已在书库 / 跳过 / 失败）。空书架的提示也补了拖拽说明。
- **同书对照按正文指纹判定**：`BookSignals` 新增 `chapterBodyShas`（去掉注文容器后逐章哈希，`ANALYSIS_KIND` 4→5）；同书分组新增「同章数 + ≥99% 正文相同」的近似判定（`NearTypesetting`）；同书对照的章级条带按正文对齐，不再要求回目全等。
- **划线 md 标题改用「书中位置 N/M」**：不再硬套「第 N 章」。

## 改进

- **顶栏位置措辞**：EPUB 从「N/M章」改成「书中位置 N/M」，翻页按钮从「上一章/下一章」改成「上一处/下一处」（TOC/spine 单位不一定是章）；PDF 仍是「第 N / M 页」「上一页/下一页」。
- 空书架补「把 EPUB / PDF 拖进窗口」的提示。

## 修复

- **同名 EPUB/PDF 不再互相挤占 `(2)`**：保存元数据改名时，唯一性只按目标格式（书文件 + 伴生 md）判断，扩展名是身份的一部分。已有 `书名 (2).pdf` 的，打开 PDF → 编辑元数据 → 直接保存即可改回 `书名.pdf`，进度/信号随之迁移。
- **整页封面在最大化时标题错位**：`ensureCoverFit` 现在返回是否为封面章；`relayout` 对封面章强制单栏（`columns:1`、`gap:0`、栏宽=整页宽），标题与 body 背景图同轴；普通正文布局不变，封面页也不再显示「双栏」。
- **文档清理**：根目录样书不再入库，验证清单改为「样本自备、放仓库外」；`book-compare` 与元数据文档同步到当前实现，`epub-stable-id` 去掉已不存在的实验脚本路径。

## 验证

- `cargo test --workspace`：iced-reader 76（+3 ignored）/ core 65 / epub 34（+2 ignored）/ pdf 17（+3 ignored），全绿。
- `cargo fmt --all -- --check`、`cargo clippy --workspace --all-targets -- -D warnings` 零告警；`npx tsc --noEmit`、`npm run check:ui` 通过。
- 真窗口：拖拽导入已由用户现场确认；整页封面同章 1098×724 / 2560×1494 截图对比通过（普通窗口不变，最大化标题回到图片正中）。
- 发布件：`IcedReader-0.19.0-windows-x64.exe`，17.53 MB，启动冒烟测试通过。

## 运行环境

Windows 10/11 x64。绿色便携：书库 / 进度 / 字体 / 窗口设置都在 exe 同级 `data/`，整个目录拷走即带走状态；不要装进 Program Files；系统需 WebView2（Windows 11 自带）。

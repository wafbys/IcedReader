# IcedReader 0.8.0

发布日期：2026-09-04

功能版：书架质量分级与同书提示正式落地——首次导入自动分析书的排版质量与正文指纹，封面左上角标 优/良/中 并可悬停查看依据；顶栏去掉品牌字。0.7.1 为纯文档补丁，本版是其后的首个功能发布。

## 功能

- **书库质量分级**：首次导入（界面显示分析反馈）计算正文指纹与质量信号，缓存到 `data/book-signals.json`（键=文件名，文件变化才重算；书架刷新只读缓存）。封面左上角标 优/良/中，未读书按质量参与排序。分级依据：正文乱码、换行符密度、图像码率（按张数估算清晰度）、标识符溯源力（ISBN / 商店号 / 自定义编号 / 随机 UUID / 无）、作者信息、章节标题结构——只使用实际测到的信号，不臆测。悬停角标弹出依据浮层：正面事实在前，良/中另有单列的「减分项」小节，一眼看清为什么没到更高评级（优通常只显示正面事实）。
- **同书提示**：正文指纹一致（同排版的重打包）或标题序列一致且总字数近乎相等（同版异排版）时，书架显示「同书 ×N」提示，不自动合并或删除。
- **顶栏清理**：去掉左上角「IcedReader」品牌字——窗口标题已含 `IcedReader 版本号`，顶栏不再重复。

## 修复

- **章节 `lang` 补全**：修复章节根标签补 `lang` 时可能插成游离文本的问题（此前会写成正文可见文本）。
- **质量角标悬停**：质量角标原本带有原生 `title` 但被 `pointer-events: none` 挡掉、悬停从不显示原因（穿透到封面按钮弹书名）；改为可悬停角标 + 自绘浮层展示依据。

## 内部

- `list_library` 的质量依据字段由单一原因列表拆为 `qualityPlus`（正面事实）/ `qualityMinus`（减分项）两组；`grade` 每次由缓存信号现算，无旧缓存迁移。
- `docs/ideas/epub-stable-id.md` 记录一条待定的「EPUB 稳定标识」想法（未实现，明确标注勿动手）。

## 下载与运行

分发文件：`IcedReader-0.8.0-windows-x64.exe`（SHA-256 `待补`，对应源码 commit `待补`）

拷贝到任意可写目录即可运行：书籍、进度、划线、字体、设置与 WebView 缓存都写在 exe 同级的 `data/` 下，拷走整个程序目录即带走全部状态。系统需 WebView2（Windows 11 自带）。

要求：Windows 10/11 x64。

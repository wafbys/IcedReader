# IcedReader 0.15.0

发布日期：2026-09-28

一句话：**划线全量进入 `<书名>.notes.md`**——每次划线即写入档案（保护区 + 摘录行），备注只是追加到该条目的用户区，不再只有写过备注的划线才进 md。

## 改进

- **划线档案**：每次划线即时在 `data/library/<书名>.notes.md` 生成一条（程序保护区注释块 + `> 【重点|摘抄】摘录（全书 N% · 划于 …）` 摘录行），按章分组。写备注只往该条目的用户区加字；清空备注只清用户区，条目不消失（划线还在，档案不该消失）。
- **位置回填**：首开新书时权重未就绪的划线（`pos` 为空）在权重到齐后，`notes.md` 该条的摘抄行「全书 N%」与 `posPct` 一并刷新，用户区逐字保留。
- **真机文案**：备注浮层提示改为「划线连同摘录已存入 notes.md；备注写进该条目的用户区」。

## 行为不变

- 删除划线：有备注的记删除时间留痕（像会计不涂改）；纯划线（从未写备注）整条移除、连因此变空的章标题一起清掉，`notes.md` 无痕。
- 外部 md 编辑器写进非保护区的文字照旧保留；程序重写只动保护区与摘录行。

## 验证

- `cargo test --workspace` 全绿；`cargo clippy --workspace --all-targets -- -D warnings` 零警告；`npx tsc --noEmit`、`npm run check:ui` 均通过。

## 运行环境

Windows 10/11 x64。绿色便携：书库 / 进度 / 字体 / 窗口设置都在 exe 同级 `data/`，整个目录拷走即带走状态；不要装进 Program Files；系统需 WebView2（Windows 11 自带）。

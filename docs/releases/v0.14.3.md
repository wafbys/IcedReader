# IcedReader 0.14.3

发布日期：2026-09-24

一句话：**首次打开新书的章权重与划线位置不再缺失**，并收紧同书对照的判定。

## 修复

- **首次打开新书**：导入后第一次打开时后台分析尚未完成，`chapterChars` 为空，导致「全书 N%」跳转消失、新建划线以 `pos=0` 落库。现在前端在 `book-signals.json` 落盘后轮询回填（`chapter_weights` 命令），并在权重到齐后按锚点回填已有划线的全书位置（`set_annotation_pos`）。
- **划线位置可空**：`Highlight.pos` 改为可空；权重未知时存 `null`，不再伪造「全书 0%」。notes.md 位置未知时写「位置未知」、`posPct` 留空。
- **PDF 同书提示**：不再是同书对照入口（`compare_books` 暂不支持 PDF），改为静态提示，保留「另有 N 本」信息。
- **逐章对照条带**：目录锚点当章的书（一个文件切成多章）不再生成错位的条带。

## 改进

- **同书提示**：标题序列回退分桶要求至少 3 条，单文件书不再被一个通用标题（如「第一章」）误判为同一本。
- **同书对照可信度**：标识符轴改用书架实时分级；图像普查被截断或来自旧版缓存时，封面 / 包内残留图轴显示「比不了」，不让缺失值当赢家。
- **安全**：章节 iframe sandbox 收回到只留 `allow-same-origin`（去掉不起作用的 `allow-popups-to-escape-sandbox`）。
- **文档**：PDF 模块文档纠正为「一页 = 一个 spine 单元、页面栅格是无损 WebP」，不再自称 spike 阶段。

## 验证

- `cargo test --workspace` 全绿；`cargo clippy --workspace --all-targets -- -D warnings` 零警告；`cargo fmt --all -- --check`、`npx tsc --noEmit`、`npm run check:ui` 均通过。

## 运行环境

Windows 10/11 x64。绿色便携：书库 / 进度 / 字体 / 窗口设置都在 exe 同级 `data/`，整个目录拷走即带走状态；不要装进 Program Files；系统需 WebView2（Windows 11 自带）。

# IcedReader 0.10.1

发布日期：2026-09-12

补丁版：修两处会让进程直接崩掉的缺陷——**开自定义字体读带中文 CSS 的 EPUB**，以及**章节切片探测 `<body>`**。都在 Rust 排版层，前端与 Tauri 命令形状未动。

## 修复

- **开自定义字体读中文书必崩**：章节 CSS 改写器逐字节扫描 `font-family` 等关键字，却对字符串做固定宽度切片。`font-family: 宋体, serif` 这类**未加引号的中文**（中文选择器同理）会让切点落进多字节字符内部而 panic。该 panic 发生在 WebView2 的资源请求回调里、不能 unwind，于是进程直接 abort（`0xc0000409`），表现为一点开就闪退。现改为按字节比较，匹配语义不变。
- **`<body>` 探测 panic**：同一类问题的另一处，`find_body_open_end` 也切了字符串。片段文档里没有 `<body>` 时会扫全串，`<p>中` 这样的内容就足以触发。同样改为字节比较。
- 两处都补了回归测试（中文 CSS、CJK 紧跟标签）；另用《史记》全本 460 章 + 920 个书内 CSS 走了一遍完整管线确认不再触发。

引号包起来的中文字体名（`font-family: "宋体"`）和 CSS 注释本来就会被跳过，所以只有一部分中文书会踩到——踩到的书在 0.10.0 上无法用自定义字体阅读，0.10.1 修好。

## 下载与运行

分发文件：`IcedReader-0.10.1-windows-x64.exe`（SHA-256 `791F3CF083888DE8E14E0951A1C0979B3C4D0110E25ACBB5228C542B03581FF9`，对应源码 commit `0c3f431`）

拷贝到任意可写目录即可运行：书籍、进度、划线、字体、设置与 WebView 缓存都写在 exe 同级的 `data/` 下，拷走整个程序目录即带走全部状态。系统需 WebView2（Windows 11 自带）。

要求：Windows 10/11 x64。

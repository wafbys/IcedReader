# IcedReader 0.6.0

发布日期：2026-09-04

这版的主功能是**书内词注**：微信读书导出类 EPUB 把词注塞在空 `<span data-wr-footernote="…">` 属性里，正文没有任何可见入口，普通阅读器打开等于没有注释。0.6.0 在 Rust 排版层把它们展开成可读的词注，并顺带修掉打开这类书（如《资治通鉴全本注译》，全书 17.9 万条词注）时的崩溃。

## 功能

- **书内词注**：被注词后出现淡棕小上标序号——**悬停即读注文全文**（原生 tooltip），**点击跳到本段后的注文块**（复用既有同文件锚点翻页）。序号由 CSS 画、正文不因此加字，章节 iframe 依旧不开脚本，划线锚定不受影响。转换只作用于 `data-wr-footernote` 属性，别的书完全无影响。词注宿主覆盖正文段落与卷题标题。
- **窗口标题可溯源**：标题显示为 `IcedReader 0.6.0 ({build 时 git 短 hash})`——编译期由 `build.rs` 注入，无 git 环境时降级为只显示版本号。发布 exe 与源码 commit 自此可以直接对上。

## 修复

- **打开大规模词注书崩溃**：词注展开器在中文正文上按字节偏移切字符串，偏移落入多字节字符内部即 panic，整个进程退出。改为字节级边界探测；并以《资治通鉴》1043 个 XHTML 文档全量验证：453 个含词注文件零残留、179,509 个注标全部生成。

## 其它

- 构建：文档补充 `npm run tauri -- build --no-bundle`（只产分发 exe、跳过安装包与 WiX/NSIS 工具下载）；安装包（NSIS/MSI）仍由 `tauri build` 生成。

## 下载与运行

分发文件：`IcedReader-0.6.0-windows-x64.exe`（SHA-256 `E45708E8D2B5A8AD5D172D90FD57BB812776305903E8D79A01924DF39995DD5C`，对应源码 commit `47764aa`）

拷贝到任意可写目录即可运行：书籍、进度、划线、字体、设置与 WebView 缓存都写在 exe 同级的 `data/` 下，拷走整个程序目录即带走全部状态。不要放进 Program Files。系统需 WebView2（Windows 11 自带）。

要求：Windows 10/11 x64。

## 说明

- 词注的悬停提示使用浏览器原生 tooltip（长注靠点击跳到段后注块读完）；更精致的浮层样式留待后续。
- 仍只支持 EPUB（2 / 3）；PDF / MOBI 等格式在接口层预留。
- 无暗色模式、无主题切换——本软件就是浅色纸。
- 尚未做：章内搜索；`Locator.cfi` 预留未填写；划线暂只支持单色与删除，彩色与笔记留待后续。

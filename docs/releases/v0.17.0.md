# IcedReader 0.17.0

发布日期：2026-10-13

一句话：**注标跳转有了落点提示**——点注标跳到注文、点返回链接跳回正文标号，落点会短暂高亮，一眼看出「跳到了哪一条」；同时修好「目录从中间开始的 EPUB 丢封面/扉页/前言」。

## 改进

- **注标跳转的落点高亮**：一章几十条注标时，只滚到目标页并不能说明落到了哪一条（同页跳转更是看起来「没反应」）。现在所有书内锚点跳转（注标→注文、注文→正文标号、目录锚点、跨章锚点）都会在目标处闪一个 1.5 秒的高亮框（琥珀底 + 描边，自行淡出；翻页/换章立即清除；长注文只标起始 160px，小到 `¹` 的标号也有可见的一小块）。高亮只画在父页，**不向章节注入任何样式**。

## 修复

- **前置页不再被目录展开吃掉**：EPUB 采用「目录锚点当章」时，如果书目的第一条从正文中间开始（《语文素养高级读本》就是从「上编」开始），OPF spine 里排在它前面的封面、扉页、前言等页面会被整批丢掉——打开书直接到第一篇，封面页看不到。现在这些页面按原顺序补在章节列表前部；第一条目录条目之后、目录未提及的页面仍由目录决定（不越权）。顺带：修复后第一章之前的页面在顶栏没有标题可显示时，只显示「第 N/M 章」，与其它无标题页一致。

## 验证

- `cargo test --workspace`：iced-reader 68（+3 ignored）/ core 65 / epub 34（+2 ignored）/ pdf 17（+3 ignored），全绿、零失败。新增单测 `toc_spine_keeps_front_matter_before_first_entry`（造一本「封面 + 扉页 + 前言 + 锚点目录」的最小样书，断言前置页保留且目录展开不变）。
- `cargo fmt --all -- --check`、`cargo clippy --workspace --all-targets -- -D warnings` 零告警；`npx tsc --noEmit` 通过；`npm run check:ui` 两条自检通过。
- 真书探针（独立小程序直接调 `crates/formats-epub`）：《语文素养高级读本》章节列表 193 → 200 项，`[0]` 从 `ch006` 变为 `cover.xhtml`，随后是扉页与 ch001–ch005。
- 真窗口实测（`scripts/ui-probe.ps1` 驱动真实窗口 + 独立便携目录）：打开《语文素养高级读本》ch008 第 1/4 页，点标题后的 `¹` → 跳到注文（4/4 页），注 1 被高亮框住；点注文开头的返回链接「1.」→ 跳回 1/4 页并高亮正文标号；两轮截图均确认高亮按时淡出。

## 运行环境

Windows 10/11 x64。绿色便携：书库 / 进度 / 字体 / 窗口设置都在 exe 同级 `data/`，整个目录拷走即带走状态；不要装进 Program Files；系统需 WebView2（Windows 11 自带）。

# IcedReader 0.7.1

发布日期：2026-09-04

补丁版：把 0.7.0 发布之后、未纳入任何发布件的文档修订收进一个正式发布件。无功能、无代码行为变化，构建产物与 0.7.0 一致，仅窗口标题内嵌的 build 时 commit hash 更新。

## 下载与运行

分发文件：`IcedReader-0.7.1-windows-x64.exe`（SHA-256 与对应源码 commit 待发布后补充）

拷贝到任意可写目录即可运行：书籍、进度、划线、字体、设置与 WebView 缓存都写在 exe 同级的 `data/` 下，拷走整个程序目录即带走全部状态。系统需 WebView2（Windows 11 自带）。

要求：Windows 10/11 x64。

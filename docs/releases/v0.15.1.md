# IcedReader 0.15.1

发布日期：2026-09-29

一句话：**删书后不再残留质量缓存**——后台分析不会再复活已删（或已改名）的书，书架列出自愈清掉任何「只剩缓存、书文件已不在」的条目。

## 修复

- **删书残留**：首开新书的分析在后台线程完成；若这本书在分析结束前被删除或改名，结束时会把条目无条件写回 `book-signals.json`（或留在旧文件名下），看起来「删了还在」。现在写入前在锁内确认文件仍在 `data/library/`，不在则丢弃这次写入。
- **书架自愈**：`list_library` 用当前书库实际文件名过一遍缓存，文件已不在的条目直接清掉；没有残留时不写盘。书无论是被外部挪走/删除，还是早先版本留下的孤儿条目，下次进书架都会清干净。

## 验证

- `cargo test --workspace` 全绿，含新增单测「删除后条目消失且迟到的分析不复活」「书架自愈清掉只剩缓存的条目」。
- `cargo clippy --workspace --all-targets -- -D warnings` 零警告。

## 运行环境

Windows 10/11 x64。绿色便携：书库 / 进度 / 字体 / 窗口设置都在 exe 同级 `data/`，整个目录拷走即带走状态；不要装进 Program Files；系统需 WebView2（Windows 11 自带）。

# IcedReader 0.10.2

发布日期：2026-09-12

界面版：元数据编辑面板不再给「没读出来的字段」显示示例占位符。功能与 Tauri 命令无变化；0.10.1 的两处崩溃修复照旧。

## 调整

- **编辑书籍信息面板**：卷册 / 作者 / 译者 / 出版年份 / ISBN 五个输入框删掉示例占位符（`如 第二部、上`、`预填原书作者，可改可清空`、`如 阳曦`、`如 2008`、`如 978-7-5366-9293-0`）。占位符只在字段为空时可见，而字段为空恰恰就是原书没读到——灰字示例容易被当成已有内容，作者那句「已预填」在没读到作者时更是说反了。现在空字段显示为空。
- 作者处说明同步改为「原书有作者则已预填（多名用半角逗号连接，中文标点不进入书名）；没读到就留空，清空则不拼入标题」。
- 保留两处不是示例的占位符：**主书名**给出清空后会回退到的名字（书名必填，校验靠它），**显示名**给出保存后真正生效的名字。只读「原书名」在缺 `dc:title` 时那句「（无书名，回退到文件名）」也保留——是解释，不是灰色示例。

## 下载与运行

分发文件：`IcedReader-0.10.2-windows-x64.exe`（SHA-256 `<构建后回填>`，对应源码 commit `<构建后回填>`）

拷贝到任意可写目录即可运行：书籍、进度、划线、字体、设置与 WebView 缓存都写在 exe 同级的 `data/` 下，拷走整个程序目录即带走全部状态。系统需 WebView2（Windows 11 自带）。

要求：Windows 10/11 x64。

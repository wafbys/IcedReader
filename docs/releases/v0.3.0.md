# IcedReader 0.3.0

发布日期：2026-09-03

这版带来**正文划线**：可以边读边划重点，划线随文字流动、跨会话保存；顶栏的「划线」会把全书标注按阅读顺序列出来，点一条就能跳回原句所在的那一页。

## 新增

- **正文划线高亮**：选中正文文字松手即浮出「划线」按钮，点击后该段文字变浅黄。划线是「书外之物」——用 CSS Custom Highlight 在原文上着色，不插入 DOM、不动版式，因此随字号调整、窗口重排、翻页、重启始终贴在原句上。
  - 再点已划线文字（无选区单击）浮出「删除划线」；双击划线里的某个词也能直接删。
  - 与已有划线重叠的选区不允许新建，需先删除旧的。
  - 锚定按章内文本节点序号，并带原文摘录兜底；存于便携目录 `data/annotations.json`，键与阅读进度同。
- **顶栏「划线」列表**：列出全书画线（按阅读顺序，含章节与摘录）。点一条跳到所在章的那一页——同章直接定位到划线所在的页，跨章自动切章；列表里也能直接删除。当前章有划线时列表内高亮。

## 修复

- **划线浮条对比度**：浅色正文底上的幽灵按钮白字对比度由 1.1:1 修复到 15:1；「划线」按钮底色改为实际的划线色（所见即所得，按钮看起来就是划上去的效果）。

## 其它

- 依赖小升：`tauri-plugin-dialog` 2.7.3、`electron-to-chromium` 1.5.420 等。
- 内部：忽略 `.codewhale/` 代理运行状态目录。

## 下载与运行

分发文件：`IcedReader-0.3.0-windows-x64.exe`（SHA-256 `CA3C1A22613A057B9C35BF37940C3D1D4C56A8C53A984559B2D67E79FAD486A0`）

拷贝到任意可写目录即可运行：书籍、进度、划线、字体、设置与 WebView 缓存都写在 exe 同级的 `data/` 下，拷走整个程序目录即带走全部状态。不要放进 Program Files。系统需 WebView2（Windows 11 自带）。

要求：Windows 10/11 x64。

## 说明

- 仍只支持 EPUB（2 / 3）。
- 无暗色模式、无主题切换——本软件就是浅色纸。
- 尚未做：章内搜索；`Locator.cfi` 预留未填写；划线暂只支持单色与删除，彩色与笔记留待后续。

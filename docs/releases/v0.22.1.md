# IcedReader 0.22.1

发布日期：2026-11-15

一句话：**正文修复 + 书架缓存版**——修复 CSS 含 Unicode 段落分隔符时 EPUB 正文空白；书架不再每次进库都全量解析 `book-signals.json` 和逐本读取伴生 md。

## 修复

- **EPUB 正文空白**：部分出版工具在 CSS 属性之间写入 `U+2029`（Unicode 段落分隔符）。字体扫描器按字节推进，遇到该字符时落进 UTF-8 字符内部并 panic，`get_chapter` 永不返回，阅读区保持空白。扫描器改为整字符跳过，并补回归测试。

## 优化

- `book-signals.json` 增加进程内 `Arc` 缓存，按文件 `(len, mtime)` 校验；写入成功后同步内存。`list_library` 不再每次全量反序列化，`prune_missing` 也只在真有失效条目时才读写。
- 伴生 md 的元数据块按纳秒级 `rev` 缓存；保存元数据、删书、改名时失效。划线、备注、用户自由笔记不进入缓存，仍按需读取。
- 19 本真实书库实测：缓存热后 `list_library` 约 10–15 ms。

## 升级

- 阅读交互、数据格式、`data/` 布局不变；进度、划线、元数据无需迁移。
- 首次启动仍需逐本打开建书架索引，首次进书架可能短暂显示空书库。

## 验证

- `cargo test --workspace`：core 71 / iced-reader 79 / epub 38 / pdf 19 通过，0 失败。
- `cargo clippy -p iced-reader --all-targets -- -D warnings`、`cargo fmt --check` 通过。
- 真窗口回归：19 本真实书库 EPUB/PDF 混排、封面、质量角标、伴生 md 标题正常；打开《阴翳礼赞》正文与脚注正常。

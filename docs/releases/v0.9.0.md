# IcedReader 0.9.0

发布日期：2026-09-04

功能版：**书名规范（书元数据编辑）**正式落地——给书架条目加一层用户可编辑元数据，显示名裁决链、伴生 Markdown、保存即按显示名改名；0.8.0 之后的第二个功能发布。

## 功能

- **编辑书籍信息（三点菜单「编辑元数据…」）**：每本书可编辑 主书名 / 副标题 / 卷册 / 作者 / 译者 / 出版年份 / 出版社 / ISBN，面板内拼接预览实时显示。「显示名」留空 = 自动按 `书名 _ 副标题 - 卷册 - 作者 - 译者 - 出版年份 - 出版社 - ISBN` 拼接（下划线只出现在书名与副标题之间，其后用 ` - `；空字段整体跳过、绝不出现连续分隔符；书名必填）；填写显示名即锁定，字段改动与「自动填充」都不会覆盖它，清空则回到自动拼接。作者 / 译者多名用半角逗号连接——书名中不出现程序产生的中文标点（顿号一律折成 ASCII）。
- **显示名裁决链**：手改显示名 → 字段拼接 → 原书 `dc:title` → 文件名。书架、阅读顶栏、删除确认共用同一结果，不分裂；元数据存成与 epub 同名的伴生 Markdown（`data/library/<书名>.md`，程序维护、可备份），删除书时一并清除。
- **保存即按显示名改名**：保存后 `data/library/` 里的 epub 与伴生 md 按最终显示名改名（Windows 禁用作文件名清洗、同名自动加 `-2`；进度 / 划线 / 质量信号缓存自动跟随——有 identifier 的书天然不丢，`lib:` 键的书自动迁键）。
- **重新读取原书元数据**：面板可一键清空手填与显示名，用原书书名 / 作者 / 出版社 / ISBN 回填表单；是否保存由你决定（原书名只读定格，不动）。
- **书架统计行**：封面网格上方显示 共 N 本 · 未读 · 已打开 · 无法打开。
- **编辑面板键盘**：模态输入框内方向键恢复移动光标（不再被全局翻页劫持）。

## 修复

- 编辑元数据输入框内按左右方向键光标不动（App 全局翻页 `preventDefault` 波及输入控件）——焦点在可编辑控件时不劫持方向键。

## 内部

- 伴生 md 为 v2 格式：`title/subtitle/volume/author/translator/year/publisher/isbn/displayTitle` + 首存定格的 `originalTitle`/`bookFile`；旧版 md 缺新字段时解析为空、不丢已有数据。宽容解析坏块忽略重建。
- `set_book_meta` 编排保存改名（`clean_file_stem` / `unique_stem` / `rename_book_files`），改名失败整次保存报错；core 增 `ProgressStore::rename_key` / `AnnotationStore::rename_book` 做 `lib:` 键迁移，`book_signals::rename_key` 随文件走。
- 符号禁则写进 AGENTS：程序生成的符号一律 ASCII 绝不产出全角；原书 `dc:title` 自带字符原样保留。

## 下载与运行

分发文件：`IcedReader-0.9.0-windows-x64.exe`（SHA-256 `D374BBE15AB852160987EFC58932D58C88ACF393958E17C0B877C5D1FDB9533E`，对应源码 commit `9c14625`）

拷贝到任意可写目录即可运行：书籍、进度、划线、字体、设置与 WebView 缓存都写在 exe 同级的 `data/` 下，拷走整个程序目录即带走全部状态。系统需 WebView2（Windows 11 自带）。

要求：Windows 10/11 x64。
